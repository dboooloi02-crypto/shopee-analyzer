Shopee 採集整合

使用 Chrome 擴充插件在 Shopee 搜尋頁採集競品數據， 採集完成後點擊擴充中的「☁ 同步到後端」按鈕， 數據自動存入 SELEKT 資料庫（埠號 8002）。

POST /api/collect/from-extension
Content-Type: application/json
→ { keyword, products: [...] }

⚠ 後端採集需安裝 Playwright：playwright install chromium

採集完成的商品儲存在「採集後端」，不會自動出現在仪表盘等分析頁面。 點擊下方按鈕將其導入到分析資料庫（自動去重，已導入過的不會重複導入）。

⚠ 導入後「進貨價(CNY)」「重量(kg)」需手動補充，仪表盘中會以 ⚠ 待補充 標示，點擊「✎」編輯。
